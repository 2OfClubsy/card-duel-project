# Roadmap

This roadmap describes the current course project outcome and the remaining Assignment 6 work for Card Duel Project.

It does not describe speculative post-course planning. The roadmap focuses on the maintained course deliverables, Week 6 trial release, Week 7 final MVP v3 delivery, and final handover status.

## Product direction

Card Duel Project is a 3D card-duel prototype with a dark room, table-centered interaction, blackjack-inspired gameplay, puzzle-related interaction, and atmospheric presentation.

The target final course version is MVP v3.

## Completed earlier increments

### MVP v1 / Week 3

Main focus:

- approved 3D card-duel direction;
- GitHub issue-based backlog;
- Sprint Backlog and MVP scope views;
- first playable prototype direction;
- customer approval of backlog, user stories, and acceptance criteria.

### MVP v2 / Assignment 5

Main focus:

- random initial card dealing;
- correct score calculation when drawing cards;
- bust / loss detection when player total exceeds 21;
- pass / end-turn behavior;
- dealer turn after player passes;
- win/loss result resolution;
- new round / restart behavior;
- architecture and quality documentation updates;
- Week 5 UAT and Sprint Review evidence.

## Assignment 6 Week 7 — Sprint 5 final MVP v3

Sprint 5 goal:

Deliver final MVP v3, respond to Week 6 customer feedback, update customer-facing documentation, confirm final transition status, publish the final MVP v3 release, and complete Week 7 public and private submission evidence.

Planned release tag:


Expected Week 7 / MVP v3 product changes:
