# Card Duel Project Documentation

This is the hosted documentation entry point for the Card Duel Project.

The documentation is maintained as part of the repository and supports Assignment 5 / MVP v2 evidence. It explains the product direction, development process, architecture, quality requirements, testing strategy, UAT scenarios, and Definition of Done.

## Project overview

Card Duel Project is a 3D card-duel prototype focused on a table-centered card interaction experience. The current Assignment 5 work focuses on MVP v2, architecture reasoning, maintainable development process documentation, quality evidence, UAT, and release traceability.
