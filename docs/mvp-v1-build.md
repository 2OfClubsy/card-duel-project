# MVP v1 Build Access

This document describes how to access and run the MVP v1 Windows build of Card Duel Project.

## Build version

MVP v1

## Platform

Windows

## Access link

The MVP v1 Windows build is available here:

[Download MVP v1 Windows build](https://drive.google.com/drive/folders/1nAm0Mkn2ATtBrYuQnAv0WJgR7ds_h5zE?usp=sharing)

## How to run

1. Download the MVP v1 Windows build archive.
2. Extract the archive to a local folder.
3. Open the extracted folder.
4. Run the .exe file.
5. Use the main menu to start a new game.

## Expected MVP v1 flow

The MVP v1 build should allow the player to:

- Start a new game from the main menu.
- Enter the 3D lobby.
- Look around the lobby.
- Interact with the card table.
- See the initial card setup.
- Experience the prototype primarily as a 3D scene.

## Verification notes

The build should be checked manually before the MVP v1 release. The verification should confirm that the expected MVP v1 flow works without crashes during the demonstrated scenario.

## Notes

MVP v1 focuses on the first playable vertical slice approved during the Week 3 customer Sprint Review. Advanced card mechanics, opponent behavior, and full round resolution are planned for later MVP versions.
