# Week 7 LLM Usage Report

## Tools used

The team used ChatGPT as a writing, planning, and documentation support tool during Assignment 6 Week 7.

## How LLMs were used

LLMs were used to support:

- planning Sprint 5 documentation tasks;
- improving presentation wording;
- shortening presentation scripts;

## Human contribution

The team reviewed, edited, and adapted the generated text to match the actual project state, customer feedback, GitHub links, issue numbers, release links, implementation progress, and submission requirements.

Project decisions, customer communication, implementation work, repository updates, final release creation, and final submission choices were made by the team.

## Limitations

LLM output was not treated as automatically correct. It required human verification against:

- Assignment 6 requirements;
- actual GitHub issues and milestones;
- actual customer feedback;
- actual implementation status;
- final build access;
- release links;
- public/private evidence rules.
