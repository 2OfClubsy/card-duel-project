# LLM Usage Report

## Tools used

The team used ChatGPT during Assignment 2.

## How the tools were used

We used ChatGPT to clarify any unclear points in Task 2 and to get suggestions on ideas we would like to implement. We also used the LLM model to quickly generate a template for filling in the text to avoid routine work and complete the task on time, meeting the Assignment 2 deadline.

The team made the final decisions about:

- product direction;
- user stories;

- initial proposed MVP v1 scope;
- customer feedback changes;
