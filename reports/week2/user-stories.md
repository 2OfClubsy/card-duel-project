# User Stories

## Personas

**New Player** — a player who opens the game for the first time and needs to understand the basic rules.

**Player** — the main user who plays card duel rounds against an opponent.

**Potential Player** — a player who wants to try the game before deciding whether to continue playing it.

**Experienced Player** — a player who wants more challenge and progression.

**Customer** — the stakeholder who wants the game to be original and attractive to players.

---

## Initial proposed MVP v1 scope

The initial proposed MVP v1 scope focuses on a small playable card duel loop with a clear interface, interesting core mechanics, and understandable challenges.

Selected user stories:

- US-05
- US-09
- US-10

These stories were selected because they are the minimum required for the first playable version. The player should be able to understand the interface, interact with the main mechanics, and understand how to overcome the game challenge.

---

## US-01: Basic tutorial

**Requirement Status:** Active  
**MoSCoW priority:** Should Have

As a new player,  
I want to pass a short in-game tutorial,  
so that I can understand the mechanics and continue playing the game.

### Notes and constraints

The tutorial should explain the basic rules and controls. It is important, but the first playable MVP can start with a simpler explanation screen.

---

## US-02: Useful cards

**Requirement Status:** Active  
**MoSCoW priority:** Could Have

As a player,  
I want to receive good cards into my deck,  
so that I have more chances to outsmart my opponent and win the game.

### Notes and constraints

For the course scope, the deck system can stay simple. Advanced card rewards and deck-building can be added later.

---

## US-03: Horror atmosphere

**Requirement Status:** Active  
**MoSCoW priority:** Should Have

As a player,  
I want to play a horror-style game,  
so that I can feel scared and tense.

### Notes and constraints

The horror atmosphere can be created through visuals, sounds, UI style, and opponent behavior.

---

## US-04: Original product concept

**Requirement Status:** Active  
**MoSCoW priority:** Could Have

As a customer,  
I want to receive an original product,  
so that it can attract attention.

### Notes and constraints

The product should feel different from a basic card game. However, the first MVP should focus on the core playable loop before adding more unique features.

---

## US-05: Clear game UI

**Requirement Status:** Active  
**MoSCoW priority:** Must Have

As a player,  
I want to see a clear UI in the game,  
so that I can play the game without any problems.

### Notes and constraints

The UI should show the player state, opponent state, available cards, and possible actions.

---

## US-06: Immersive 3D presentation

**Requirement Status:** Active
**MoSCoW priority:** Should Have

As a player,
I want the game to have an immersive 3D presentation,
so that I can feel more involved in the horror atmosphere and game world.

### Notes and constraints

The customer suggested using a mostly 3D format because immersion is important for this type of game. 2D elements can still be used where appropriate, such as UI, cards, menus, and visual overlays.

---

## US-07: Enough content

**Requirement Status:** Active  
**MoSCoW priority:** Should Have

As a player,  
I want to have enough content,  
so that I can spend more time in the game.

### Notes and constraints

Additional content may include more cards, more opponents, and more events. This can be expanded after the core loop is tested.

---

## US-08: Difficulty progression

**Requirement Status:** Active  
**MoSCoW priority:** Could Have

As an experienced player,  
I want difficulty progression,  
so that I feel involved in the game.

### Notes and constraints

Difficulty progression can be added through stronger opponents, harder rules, or limited resources.

---

## US-09: Interesting mechanics

**Requirement Status:** Active  
**MoSCoW priority:** Must Have

As a player,  
I want to see interesting mechanics,  
so that the game does not seem boring and repetitive.

### Notes and constraints

For MVP v1, this can be represented by a small set of cards with different effects.

---

## US-10: Understandable challenges

**Requirement Status:** Active  
**MoSCoW priority:** Must Have

As a player,  
I want to understand how to overcome obstacles,  
so that I can complete the game and not abandon it after a short time.

### Notes and constraints

The game should clearly show the goal, available actions, and results of player decisions.
