# Week 3 Report — Assignment 3

## Project information

**Project name:** Card Duel Project
**Team:** Team #31
**Repository:** https://github.com/2OfClubsy/card-duel-project

Card Duel Project is a 3D card-duel prototype focused on a dark tabletop card-game experience. The approved MVP v1 direction focuses on the first playable vertical slice: starting a game, entering a 3D lobby, interacting with the card table, and seeing the initial card setup.

### MVP v1 expected flow

The MVP v1 build should allow the player to:

* Start a new game from the main menu.
* Enter the 3D lobby.
* Look around the lobby.
* Interact with the card table.
* See the initial card setup.
* Experience the prototype primarily as a 3D scene.

The Google Drive folder contains the MVP v1 demo video and the game archive in `.rar` format.

## Known limitations and future work

MVP v1 focuses on the first playable vertical slice. Advanced card selection, opponent behavior, full round resolution, and deeper card mechanics are planned for later MVP versions.

The customer also suggested that art references could be added later to make the visual direction more complete, but this was not required for MVP v1 approval.
