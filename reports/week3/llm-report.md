# LLM Usage Report

## Tools used

During Assignment 3, the team used ChatGPT as an LLM-based assistant.

## How LLM tools were used

The team used LLM assistance mainly for planning, documentation structure, and GitHub workflow organization.

LLM assistance was used for:

* Understanding Assignment 3 requirements.
* Planning the GitHub workflow step by step.
* Structuring GitHub Issues, labels, milestones, and Project views.
* Structuring Week 3 report files.

## Human review and original team work

The LLM was used as a support tool, not as a replacement for team work.

All generated or suggested content was reviewed and adjusted by the team before being added to the repository. The team checked that the content matched the real project state, including:

* Actual team members and GitHub usernames.
* Actual issue numbers.
* Actual pull request links.
* Actual GitHub Project views.
* Actual MVP v1 scope.
* Actual customer feedback from the offline Sprint Review.
* Actual release, build, and demo links.

The final decisions, repository changes, customer communication, MVP v1 evidence, and submitted artifacts remained the responsibility of the team.

## Customer review documentation

The Week 3 customer Sprint Review was conducted offline and was not recorded.

The team did not use LLM tools to fabricate a transcript. Since the meeting was offline and not recorded, the repository contains written notes and a summary instead of a transcript.

## Code and implementation

LLM tools were not used as an automatic replacement for implementation work.

The main use of LLM assistance in Assignment 3 was related to:

* Documentation.
* Process organization.
* Report structure.

Team members still created issue-linked branches, pull requests, reviews, screenshots, release evidence, and documentation updates through the repository workflow.

The final Assignment 3 artifacts contain team-reviewed content, actual repository evidence, actual customer review evidence, and original team work.
