# 3D Lobby Evidence

This document records evidence for MVP v1 user story US-002: Enter the 3D lobby.

## Related issue

- #24 US-002: Enter the 3D lobby

## User story

As a player, I want to enter a 3D lobby so that the game feels immersive before the card duel starts.

## MVP v1 context

The 3D lobby is part of the approved MVP v1 direction. During the Week 3 customer Sprint Review, the customer approved the current backlog structure, MVP v1 scope, user stories, and acceptance criteria.

## Implemented behavior

The MVP v1 flow allows the player to:

1. Start a new game from the main menu.
2. Enter the 3D lobby scene.
3. See the room/lobby environment.
4. Continue toward the table interaction flow.

## Acceptance criteria verification

- [x] The player enters a 3D scene after starting the game.
- [x] The scene contains a visible lobby or room environment.
- [x] The 3D environment supports the intended atmosphere of the card duel prototype.

## Evidence notes

The lobby supports the first playable vertical slice by giving the player a 3D scene before the card duel setup. The current MVP v1 implementation focuses on atmosphere and navigation into the table/card setup rather than full walking movement or advanced gameplay mechanics.

## Known limitations

- Free walking movement is not part of the MVP v1 scope.
- Advanced environmental polish is planned for later MVP versions.
- Additional art references may be added later as an optional improvement, but they are not required for MVP v1 approval.

## Conclusion

The 3D lobby behavior satisfies the MVP v1 acceptance criteria for US-002.
