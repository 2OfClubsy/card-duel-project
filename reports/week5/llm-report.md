## Purpose of this report

This report describes how AI / LLM tools were used during Assignment 5.

The team used LLM tools mainly as a time-saving assistant for preparing and filling GitHub documentation, report drafts, checklist structures, and workflow-related explanations. This helped the team work faster and stay within the Assignment 5 deadline while still keeping the final decisions under team control.

LLM assistance was also used to receive advice about GitHub workflow organization, including issue-linked Pull Requests, milestone usage, project board structure, documentation traceability, and public/private evidence separation.

All final decisions, repository changes, wording choices, evidence links, and submitted artifacts were reviewed and accepted by the project team. The LLM was used as a support tool, not as an independent decision-maker.
