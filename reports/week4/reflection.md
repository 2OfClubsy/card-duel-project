# Week 4 Reflection

This document contains the public reflection for Week 4 of Card Duel Project.

## What was completed

During Week 4, the team focused on preparing the Assignment 4 increment and improving the project evidence.

The main completed work includes:

- Sprint 2 planning and Sprint Backlog update;
- source-level Godot project setup in the repository;
- updated README with run-from-source instructions;
- quality requirements;
- quality requirement tests;
- testing documentation;
- updated Definition of Done;
- automated repository quality checks;
- CI checks;
- Week 4 customer UAT scenarios;
- customer UAT and Sprint Review notes;
- customer review summary.

## What changed compared to MVP v1

Compared to MVP v1, the team showed the customer the following MVP v2 progress:

- pause menu;
- ability to select cards from the table;
- foundation for a blackjack system.

The blackjack system is not fully playable yet, so it is documented as a follow-up instead of being presented as a fully completed gameplay feature.

## Customer feedback reflection

The customer generally approved the Sprint Backlog and MVP v2 direction.

The customer completed all prepared UAT scenarios without blocking issues.

The most important feedback was that the blackjack system should be completed before it is presented as a fully working MVP v2 feature.

The customer also confirmed that the team continues to follow one of the main early feedback points: the game should remain a 3D card-duel experience instead of becoming a simple 2D prototype.

## Quality reflection

Week 4 improved the repository quality because the project now contains source-level setup and automated checks.

The repository now includes:

- Godot source project under `game/`;
- run-from-source instructions;
- quality requirements;
- quality requirement tests;
- testing documentation;
- CI checks.

This addresses the previous issue where the repository looked like it contained mainly documentation and configuration instead of product source.

## What should be improved next

The main next improvements are:

- complete blackjack gameplay;
- improve table card interaction feedback;
- continue developing the 3D card-duel experience;
- add more product-level automated tests when the Godot testing setup is ready;
- continue keeping public and private evidence separated.
