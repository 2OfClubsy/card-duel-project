# Week 4 LLM Usage Report

This document describes how Large Language Model tools were used during Week 4 of Card Duel Project.

## Purpose of LLM usage

The team used an LLM assistant to reduce the time needed for preparing GitHub documentation and to stay within the Assignment 4 deadline.

The LLM was used mainly as a drafting and workflow support tool, not as a replacement for team decisions.

## Areas where LLM was used

| Area | How the LLM was used |
|---|---|
| GitHub documentation | The LLM helped draft and structure documentation files for Week 4 evidence. |
| Week report preparation | The LLM helped organize report sections, evidence links, summaries, and public/private evidence notes. |
| Quality documentation | The LLM helped draft initial versions of quality requirements, quality requirement tests, testing documentation, and Definition of Done updates. |
| GitHub workflow support | The LLM provided advice about issues, branches, pull requests, CI checks, review comments, and merge order. |
| Customer UAT evidence | The LLM helped convert customer meeting notes into sanitized public UAT summaries and customer review notes. |
| Retrospective and reflection | The LLM helped structure reflection and retrospective documents based on the team’s real Sprint results. |

## Human review and team decisions

All final decisions were reviewed and accepted by the project team.

The team checked the generated documentation before committing it to the repository.

The LLM did not independently decide the project scope, customer feedback, Sprint Backlog, Product Backlog, or final MVP direction.

The customer feedback, UAT results, and Sprint Review conclusions were based on the actual customer meeting.

## Limitations

The team treated LLM output as draft material.

Some generated markdown had to be manually checked and corrected before being committed.

The team also verified that public files did not include private customer information, private recording links, credentials, university emails, or confidential evidence.

## Conclusion

The LLM was used as a productivity and workflow support tool.

It helped the team prepare documentation faster and organize Assignment 4 evidence more clearly, while the final content, project decisions, and customer-related conclusions remained under team control.
