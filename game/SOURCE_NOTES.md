# Game Source Notes

This folder contains the Godot source project for Card Duel Project.

- Godot version: 4.6.stable
- Source entry point: `game/project.godot`
- Main project folders are preserved from the original Godot project.

Cleanup performed before adding to the course repository:

- Embedded `.git/` history was removed.
- Exported build archives and executable artifacts were excluded.
- Godot local cache folders were excluded when present.
- Font binaries were excluded from this cleaned package. Add only fonts that the team has permission to redistribute, or replace them with licensed alternatives.
- `export_presets.cfg` was excluded because it may contain local machine export paths.

If the project needs the excluded fonts to display exactly as in the original build, verify font licenses first and document them before committing.
